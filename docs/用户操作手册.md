# 党政工作智脑 — 用户操作手册

> 版本：v1.0 | 更新日期：2026年2月28日

---

## 一、系统简介

党政工作智脑是面向机关党委的AI智能助手，提供以下核心功能：

| 功能 | 说明 |
|------|------|
| 文档模板生成 | 输入关键信息，自动生成工作计划、活动方案等文档 |
| 党员信息查询 | 自然语言查询党员数据、统计分析 |
| 政策法规咨询 | 解答政策问题，附带条款引用 |
| 合规条件判断 | 逐条对照判断是否满足规定，给出置信度 |
| 文件差异对比 | 对比两份文件内容差异，生成差异报告 |

---

## 二、登录与界面

### 2.1 登录

1. 打开浏览器访问系统地址（如 http://localhost:3000）
2. 输入用户名和密码
3. 点击「登录」按钮

### 2.2 主界面布局

登录后进入主对话页面，界面分为三个区域：

| 区域 | 位置 | 功能 |
|------|------|------|
| 左侧栏 | 左侧 | 快捷入口、常用查询、历史对话、系统管理（管理员可见） |
| 对话区 | 中央 | 与AI对话的主区域，显示消息气泡 |
| 输入区 | 底部 | 输入问题并发送，支持流式/标准模式切换 |

### 2.3 两种对话模式

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| 流式模式 | AI回复逐字显示（默认） | 通用对话、政策咨询 |
| 标准模式 | 等待完整响应，支持表格/图表/卡片 | 党员查询、统计分析、合规判断 |

点击输入框下方的「切换为标准模式/流式模式」可切换。

## 三、功能一：文档模板生成

### 3.1 基本流程

```
输入需求 → 匹配模板 → 填写信息 → 生成大纲 → 确认 → 生成全文 → 下载
```

### 3.2 操作步骤

**第1步：描述需求**

在对话框中输入文档需求，例如：
- "帮我写一份七一活动策划方案"
- "帮我写一份年度工作计划"
- "帮我写一份述职报告"

**第2步：填写信息**

系统匹配模板后，会弹出信息表单。红色标记的为必填字段，灰色为选填。

示例表单字段：
- 活动主题（必填）
- 活动时间（必填）
- 活动地点（必填）
- 参与人数（必填）
- 活动预算（选填）

填写完毕后点击「确认生成」。

**第3步：确认大纲**

系统先生成文档大纲供您确认。确认无误后点击「确认，生成全文」。

如果大纲不满意，可以点击「重新生成大纲」。

**第4步：查看并下载**

完整文档生成后，您可以：
- 点击「下载Word」下载 .docx 文件
- 点击「下载PDF」下载 .pdf 文件
- 点击「继续修改」对文档进行调整

### 3.3 迭代修改

点击「继续修改」后，在弹出的输入框中描述修改要求：
- "把预算部分再详细些"
- "增加一个茶歇环节"
- "把时间改为下午2点"

系统会根据您的要求修改文档，修改后仍可继续修改或下载。

### 3.4 可用模板列表

| 模板名称 | 类型 | 必填字段 |
|---------|------|---------|
| 年度工作计划 | 计划 | 年度、部门名称、工作目标 |
| 活动策划方案 | 方案 | 活动主题、活动时间、活动地点、参与人数 |
| 季度工作总结 | 总结 | 季度、部门名称 |
| 会议纪要 | 记录 | 会议名称、会议时间、会议地点、主持人 |
| 党员发展方案 | 方案 | 年度、发展计划人数 |
| 述职报告 | 报告 | 述职人姓名、职务、述职年度 |

## 四、功能二：党员信息查询与统计

### 4.1 自然语言查询

在对话框中用自然语言提问，系统会自动转换为数据库查询。

**查询示例**：
- "第三党支部有哪些预备党员？"
- "张三是哪个支部的？"
- "查询所有30岁以下的党员"

**统计示例**：
- "统计各支部的党员人数"
- "统计党员年龄分布"

> 提示：统计类查询建议使用「标准模式」，以便显示表格和图表。

### 4.2 常用查询

左侧栏「常用查询」区域提供4个预设查询，点击即可直接执行：
- 各支部党员人数
- 年龄段分布
- 预备党员名单
- 全部党员名单

### 4.3 查看结果

查询结果以以下形式展示：

| 结果类型 | 展示方式 |
|---------|---------|
| 多人列表 | 数据表格（支持分页） |
| 单人查询 | 画像卡片（头像+姓名+支部+详细信息） |
| 统计分析 | 表格 + ECharts图表（柱状图/饼图可切换） |

### 4.4 导出数据

查询结果下方有「导出Excel」按钮，点击可下载 .xlsx 文件。

### 4.5 数据脱敏

为保护个人隐私，手机号等敏感字段会自动脱敏展示（如：138\*\*\*\*5678）。

## 五、功能三：政策法规咨询

### 5.1 政策咨询

在对话框中提问政策问题：
- "党费缴纳标准是什么？"
- "发展党员的基本流程是什么？"
- "组织生活会的要求有哪些？"

系统会检索知识库中的相关条款，结合AI生成回答，并在末尾标注引用来源。

### 5.2 查看引用

回答下方会显示紫色引用块，可折叠展开查看：
- 引用来源（政策文件名）
- 条款标题和层级
- 条款原文内容

### 5.3 合规判断

描述一个具体情况，让系统判断是否符合规定：
- "李四22岁，递交入党申请书满1年，党课已结业，能否确定为入党积极分子？"
- "王五入党时间满一年，能否转为正式党员？"

> 提示：合规判断建议使用「标准模式」，以便显示结构化的判断卡片。

### 5.4 判断结果卡片

合规判断结果以卡片形式展示：
- **逐条核查表**：每个条件显示 PASS（通过）/ FAIL（不通过）/ ????（信息不足）
- **置信度**：进度条展示判断的可信程度
- **引用依据**：标注判断所依据的具体条款
- **补充建议**：标注需要补充的信息

### 5.5 补充材料重新判断

如果判断结果中有信息不足的项，点击「补充材料重新判断」：
1. 在弹出框中输入补充信息
2. 系统重新进行合规判断

## 六、功能四：文件差异对比

### 6.1 使用方式

**方式一：管理后台**
1. 点击左侧「系统管理」→ 进入管理后台
2. 选择「文件对比」菜单
3. 上传文件1（旧版）和文件2（新版）
4. 点击「开始对比」

**方式二：对话触发**
在对话中提到"对比"、"差异"等关键词，系统会引导您前往文件对比页面。

### 6.2 支持的文件格式

- PDF (.pdf)
- Word (.docx)
- 纯文本 (.txt)

### 6.3 差异报告

对比结果包含：
- **文件信息**：两份文件的名称
- **差异数量**：总共发现几处差异
- **相似度**：两份文件的整体相似度百分比
- **差异汇总**：修改X处 / 新增X处 / 删除X处
- **逐条差异**：每处差异的旧版内容（红底）和新版内容（绿底），附变更说明

## 七、对话历史管理

### 7.1 新建对话

点击左侧栏顶部的「新对话」按钮，开启一个新的对话。

### 7.2 查看历史

左侧栏「历史对话」区域显示最近15条对话记录。点击任意一条可切换查看。

### 7.3 删除对话

将鼠标移到历史对话上，右侧出现 ✕ 图标，点击即可删除该对话。

## 八、常见问题

### Q: 为什么AI回复说"模型未连接"？
A: LLM模型服务未配置或不可用。请联系管理员在管理后台 → LLM配置中检查设置。

### Q: 查询党员信息显示"未查询到数据"？
A: 可能尚未导入党员数据。请联系管理员通过管理后台导入党员Excel表。

### Q: 政策咨询的回答没有引用来源？
A: 可能尚未上传政策文件到知识库。请联系管理员上传并解析政策PDF/Word文件。

### Q: 表格和图表没有显示？
A: 请切换到「标准模式」（输入框下方切换按钮），流式模式不支持结构化数据展示。

### Q: 如何导出生成的文档？
A: 文档生成后，点击「下载Word」或「下载PDF」按钮即可下载。
