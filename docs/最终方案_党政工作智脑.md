## 三、功能模块详细设计

### 3.1 功能一：辅助生成（模板填充）

**目标**：用户输入关键信息，系统自动填充模板生成完整文档。

**实现方案**：
1. 模板结构化存储（名称、类型、必填字段、可选字段、正文骨架）
2. 模板采用 Jinja2/Mustache 格式，支持动态字段
3. LLM 使用 few-shot + 模板约束 prompt，确保格式统一
4. 两阶段生成：先生成大纲确认 → 再生成完整文档
5. 支持迭代修改指令（如"把预算部分再详细些"）
6. 文档导出 Word/PDF（python-docx / reportlab）

**交互流程**：
```
用户："帮我写一份七一活动策划方案"
  -> 意图识别 -> 匹配"活动策划方案"模板
  -> 追问缺失字段（时间、地点、人数、预算）
  -> 用户补充 -> 先生成大纲确认
  -> 确认后生成完整方案 -> 在线预览 & 导出
```

### 3.2 功能二：知识问答（党员查询 & 统计）

**目标**：通过自然语言查询党员信息和数据统计分析。

**实现方案**：
1. 党员信息导入MySQL，标准字段：姓名、性别、出生日期、入党日期、部门/支部、职务、学历、电话、状态等
2. NL2SQL模块：LLM + 数据库schema注入，自然语言转SQL
3. 安全兜底：SQL白名单校验（只允许SELECT）
4. 统计结果支持表格 + ECharts图表双形态
5. 敏感信息脱敏（手机号等）
6. 结果分页（每页20条）
7. 常用查询历史记录功能

### 3.3 功能三：政策规则库 + 合规判断

**目标**：构建政策知识库，检索条款并判断合规性。

**实现方案**：
1. 知识库构建流水线：文档解析 -> 文本清洗 -> 按章节/条款切片 -> Embedding向量化 -> 存入Milvus
2. 混合检索（向量+关键词）+ Rerank重排序
3. 判断结果附带原文引用，可查证可追溯
4. 置信度阈值80%，低于阈值提示"建议人工复核"
5. 支持"补充材料重新判断"和"假设判断"模式
6. 政策文件增量更新（新增/替换/废止）

## 四、技术选型

| 组件 | 推荐方案 | 备选方案 | 选型理由 |
|------|---------|---------|---------|
| 大语言模型 | 私有化部署 Qwen2.5/DeepSeek | 通义千问/智谱API | 涉及党员信息，建议私有化 |
| Embedding | bge-large-zh-v1.5 | m3e-large | 中文效果最佳 |
| Rerank | bge-reranker-v2-m3 | - | 提升检索精度 |
| 向量数据库 | Milvus | FAISS/Chroma | 生产级，支持分布式 |
| 结构化数据库 | MySQL 8.0 | PostgreSQL | 运维成本低 |
| 文档解析 | PyMuPDF + python-docx | Unstructured.io | 轻量高效 |
| 后端框架 | Python FastAPI | Flask | 异步高性能 |
| 前端框架 | React + Ant Design | Vue3 + Element Plus | 企业级组件丰富 |
| 图表库 | ECharts | Chart.js | 中文支持好 |
| 对话框架 | LangChain/LlamaIndex | 自研Agent | 生态成熟 |
| 文档导出 | python-docx + reportlab | WeasyPrint | Word+PDF双格式 |

**硬件建议**：

| 组件 | 最低配置 | 推荐配置 |
|------|---------|---------|

## 十、验收标准

### 10.1 功能验收

| 验收项 | 标准 | 验收方式 |
|--------|------|---------|
| 模板生成 | 所有模板可正确填充，格式统一，Word/PDF可导出 | 逐模板测试 |
| 党员查询 | 常见查询准确率>=95% | 50条测试用例 |
| 政策咨询 | 回答准确且附带引用，准确率>=90% | 30条测试用例 |
| 合规判断 | 逐条对照，置信度合理，引用正确 | 20条测试用例 |
| 差异对比 | 差异识别准确，分类清晰，可导出 | 5组对比文件 |

### 10.2 性能验收

| 指标 | 标准 |
|------|------|
| 党员查询响应 | <= 3秒 |
| 统计分析响应 | <= 5秒 |
| 模板生成响应 | <= 15秒 |
| 政策咨询响应 | <= 10秒（流式首字<=2秒） |
| 合规判断响应 | <= 15秒 |
| 并发支持 | >= 10人同时使用 |

### 10.3 安全验收

| 验收项 | 标准 |
|--------|------|
| 数据存储 | 全部数据存储在内网服务器 |
| LLM调用 | 私有化部署，不外传数据 |
| 敏感信息 | 手机号等字段脱敏展示 |
| 操作日志 | 全部操作可追溯审计 |
| 权限控制 | 管理员/普通用户分级 |
